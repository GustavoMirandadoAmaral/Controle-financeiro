# Registro de Decisões do Projeto

Este documento serve como um histórico (semelhante a um *Architecture Decision Record - ADR* usado em empresas grandes) para registrar todas as escolhas técnicas e de negócios feitas por você durante a construção do nosso sistema.

---

### Decisão 001: Framework Frontend
- **Decisão:** Utilizar o framework **Next.js** (baseado em React).
- **Motivação:** Escolha alinhada com o padrão atual do mercado. O Next.js fornece uma arquitetura profissional pronta para uso, roteamento otimizado e facilita a escalabilidade da aplicação.

### Decisão 002: Linguagem Base
- **Decisão:** Utilizar **JavaScript**.
- **Motivação:** Permite maior agilidade no desenvolvimento inicial do Produto Mínimo Viável (MVP), mantendo a porta aberta para uma futura adoção de TypeScript, caso o projeto cresça e exija maior tipagem.
