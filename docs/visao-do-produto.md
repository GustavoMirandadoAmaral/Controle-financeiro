# Visão do Produto: Controle Financeiro Pessoal

## Objetivo
Criar uma aplicação web moderna para controle financeiro pessoal, permitindo o registro e acompanhamento de despesas, receitas e investimentos de forma intuitiva e visual.

## Público-Alvo
Usuários que desejam ter um controle rigoroso sobre suas finanças pessoais de maneira simplificada, com acesso a relatórios e gráficos.

## Funcionalidades Principais (MVP - Produto Mínimo Viável)
1. **Dashboard:** Visão geral com saldo atual, total de receitas, total de despesas e gráficos de desempenho.
2. **Gestão de Transações:** Cadastro, edição e exclusão de receitas e despesas (com categorias e datas).
3. **Gestão de Investimentos:** Acompanhamento de carteira de investimentos e rendimentos.
4. **Relatórios:** Geração de relatórios mensais/anuais.

## Tecnologias Escolhidas
- **Framework:** Next.js (Padrão de mercado atual para aplicações React)
- **Linguagem:** JavaScript (Podendo evoluir para TypeScript futuramente)
- **Estilização:** Tailwind CSS ou CSS Modules
- **Gerenciamento de Estado:** Context API ou Zustand
