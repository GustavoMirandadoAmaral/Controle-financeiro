# Controle Financeiro Pessoal

Um sistema moderno e interativo para controle de finanças pessoais, projetado para oferecer uma experiência visual rica e facilitar o acompanhamento de despesas, receitas e investimentos.

## 🚀 Tecnologias Utilizadas
- **Next.js** (App Router)
- **React.js**
- **JavaScript**
- **Tailwind CSS** (Para estilização e design system)

## 💻 Como rodar o projeto localmente

Como o projeto foi criado com o Next.js, basta instalar as dependências e rodar o servidor de desenvolvimento:

```bash
# 1. Certifique-se de estar na raiz do projeto
# 2. Instale as dependências (se ainda não tiver instalado)
npm install

# 3. Rode o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.
O código principal das telas começará a partir da pasta `src/app/`.
